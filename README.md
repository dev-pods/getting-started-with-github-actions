# GitHub Actions: do primeiro workflow à entrega contínua

_Aprenda a testar alterações, compartilhar artefatos e publicar um site com GitHub Actions._

## Boas-vindas

- **Para quem é:** pessoas começando com GitHub Actions. Não é preciso saber programar.
- **O que você vai aprender:** criar workflows, acompanhar testes e transferir artefatos entre jobs.
- **O que você vai construir:** um portal de equipe publicado no GitHub Pages.
- **Pré-requisitos:** conta GitHub, Codespaces, Actions e Pages habilitados, navegador e internet. O Codespaces tem cota de uso; consulte [os detalhes](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).
- **Duração:** 50–60 minutos, com o Codespaces pronto. O Passo 6 é opcional (+12 minutos).

Neste exercício, você vai:

1. Criar um workflow de boas-vindas.
2. Executar testes e investigar uma falha.
3. Gerar e compartilhar artefatos entre jobs.
4. Publicar o site no GitHub Pages.
5. _(Opcional)_ Reutilizar etapas em uma composite action.

### Como iniciar este exercício

Copie o exercício para sua conta do GitHub e siga as instruções da Mona na issue. O Passo 1 mostra como abrir o Codespaces.
